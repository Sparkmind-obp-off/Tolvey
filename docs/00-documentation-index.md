## Status vocabulary

Every document and presentation should distinguish:
- Implemented
- Verified
- Planned
- Hypothesis
- Blocked

Documentation is not implementation evidence.

## Engineering phase rule

A phase is one complete gate.

Credit/session limits may require multiple Genspark working sessions, but they do not create Phase A/B/C subdivisions.

## Documentation change rule

When implementation changes:
1. update the affected canonical document;
2. mark the actual implementation state;
3. do not rewrite planned work as completed;
4. preserve architecture decisions and reasons;
5. update the presentation brief when evidence changes.
