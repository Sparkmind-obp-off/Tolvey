# TOLVEY Marketplace Listing Standard

Status: Distribution content specification
Version: v1.0
Updated: 2026-09-30

## Listing package
Every channel listing should have:
1. Channel-specific title.
2. Short value proposition.
3. Buyer/problem statement.
4. Outcome.
5. Contents.
6. Format and delivery method.
7. Compatibility requirements.
8. License/use rights.
9. Version.
10. Support policy.
11. Preview images.
12. FAQ.
13. Clear limitations.
14. Refund/consumer information where required by channel.
15. Canonical product ID internally.

## Listing principle
Sell the job and outcome, not vague claims such as “make money fast” or “guaranteed success.”

## Creative variants
Maintain reusable creative concepts:
- product walkthrough
- before/after workflow
- problem/solution
- use-case demonstration
- tutorial
- customer feedback when genuine and permissioned

## Localization
Create Indonesian and English versions only when there is a real distribution reason. Do not duplicate catalogs without a channel or audience rationale.
